## Rollback

- **Fastest:** DigitalOcean console → Deployments → the previous deployment (`8a3fbc2`) → Redeploy.
- **Git (no force push):** a forward commit whose tree is the current production:
  ```
  git checkout -b rollback/2026-10-09 release/2026-10-09
  git read-tree -u --reset 8a3fbc2
  git commit -m "revert: roll back to 8a3fbc2"
  git push vsite rollback/2026-10-09:master
  ```
- Migration 066 needs no rollback (old code never calls it); to remove it:
  `DROP FUNCTION IF EXISTS public.menu_scan_counts(uuid, timestamptz); DROP INDEX IF EXISTS public.menu_scans_site_visitor_idx;`
- Photo repair: the plan file lists `{ id, from, to }`; set `image_url` back to `from` to restore a dish.
  The sweep's deletions cannot be undone — that is why it deletes only a reviewed manifest.
